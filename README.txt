ملفات الرفع — 5 ملفات فقط
=========================
index.html            ← البرنامج كاملاً (ملف واحد، بلا أي اعتماد خارجي)
sw.js                 ← عامل الخدمة (تشغيل دون إنترنت + التحديث)
manifest.webmanifest  ← بيانات التثبيت على الهاتف
icon-192.png
icon-512.png
netlify.toml          ← اختياري (رؤوس أمان + منع تخزين sw.js)

طرق الرفع السريعة
-----------------
1) Netlify:  اسحب هذا المجلد إلى app.netlify.com/drop  → رابط https جاهز.
2) GitHub Pages: ارفع محتويات هذا المجلد إلى المستودع ← Settings ← Pages ← Branch: main / root.
3) Cloudflare Pages: Upload assets ← هذا المجلد.
4) أي استضافة ملفات ثابتة (cPanel/دومين خاص): ارفع الخمسة ملفات إلى public_html.

مهم
---
• يجب أن يكون الموقع على HTTPS — عامر الخدمة والتشفير لا يعملان على HTTP عادي.
• بعد كل تحديث للبرنامج: بدّل رقم الإصدار في sw.js (hisabat-vNN) ثم ارفع الملفات الخمسة.
• بعد الرفع: افتح الرابط ← الإعدادات ← بطاقة المزامنة ← الصق Project URL و anon key من Supabase
  ← أنشئ حساباً ← كرّر الدخول بنفس الحساب على الهاتف.
